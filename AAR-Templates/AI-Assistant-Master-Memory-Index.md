# AI Assistant Master Memory Index

## 1. Purpose

This document is the central navigation and recovery index
for AI-assisted work.

Its objectives are to:

- Preserve verified information across conversations.
- Locate important decisions and corrections.
- Recover project context after memory loss.
- Prevent repeated errors.
- Maintain continuity across ongoing projects.
- Support evidence-based research and recommendations.

This index is an external reference system.
It does not automatically synchronize with AI memory.

## 2. Memory Recovery Priority

When recovering context, consult sources in this order:

1. Current user instructions and current conversation.
2. Relevant verified project records.
3. Current authoritative external sources.
4. Previous decisions and corrections.
5. Historical conversation summaries.

If information conflicts, identify the conflict
and prioritize current, verified evidence.

Never silently replace an explicit user instruction
with an older preference.

## 5. Critical Verification Rules

Before completing a task:

1. Review relevant previous decisions.
2. Check the error register.
3. Verify source information.
4. Identify unsupported assumptions.
5. Confirm that deliverables meet requirements.
6. Verify actual completion.
7. Record significant corrections.

## 6. Employment Research Rules

For employment searches:

- Verify the employer and actual vacancy.
- Check the employer's official application page.
- Confirm location eligibility.
- Confirm employment structure.
- Review mandatory qualifications.
- Check previous applications.
- Exclude rejected or closed opportunities.
- Avoid duplicate recommendations.
- Distinguish verified jobs from unconfirmed leads.

Detailed employment requirements must be maintained
in dedicated project records.

## 7. Document Quality Rules

Before delivering documents:

- Verify names and dates.
- Check factual accuracy.
- Validate formatting.
- Confirm required sections are included.
- Confirm generated files exist.
- Preserve approved information.
- Do not invent qualifications or accomplishments.

## 8. Error Prevention Workflow

### Identify

Determine whether a similar mistake occurred previously.

### Investigate

Review the error register and supporting evidence.

### Correct

Apply the documented correction.

### Verify

Confirm that the correction addresses the problem.

### Record

Update the relevant register when necessary.

## 9. Decision Management

Important decisions should include:

- Decision identifier
- Decision date
- Project
- Decision description
- Supporting evidence
- Current status
- Superseded decision, if applicable

## 10. Context Recovery Procedure

When conversation context is missing:

1. Identify the current project.
2. Open this Master Memory Index.
3. Locate relevant reference documents.
4. Review the latest verified decisions.
5. Check known errors and prevention rules.
6. Identify missing information.
7. Verify current external facts when needed.
8. Resume work using the recovered context.

If required information is unavailable,
state the limitation rather than guessing.

## 12. Confidentiality

Do not store passwords, authentication tokens,
government identification numbers, private medical
information, confidential communications, or other
sensitive personal information in public repositories.

Store sensitive records in approved private systems.

## 13. Important Limitations

This index is not an automatic memory service.

An AI assistant must retrieve the repository
and inspect the relevant documents before relying
on their contents.

The index supports continuity and error prevention,
but does not guarantee perfect recall or accuracy.
