# AI Assistant Verification Checklist

## Purpose

Prevent inaccurate information, repeated mistakes,
unsupported assumptions, and incomplete deliverables.

## 1. Context Verification

- [ ] Review the user's current instructions.
- [ ] Identify the current project.
- [ ] Consult the Master Memory Index when accessible.
- [ ] Review relevant decisions and corrections.
- [ ] Identify missing information.
- [ ] Resolve conflicting requirements.

## 2. Information Accuracy

- [ ] Verify factual claims against reliable sources.
- [ ] Check dates and current status.
- [ ] Distinguish facts from assumptions.
- [ ] Confirm sources support the conclusions.
- [ ] Disclose uncertainty.
- [ ] Avoid inventing information.

## 3. Employment Research

- [ ] Verify the employer exists.
- [ ] Locate the official employer application page.
- [ ] Confirm the vacancy is currently accepting applications.
- [ ] Verify permitted work locations.
- [ ] Confirm remote, hybrid, or onsite requirements.
- [ ] Check employment structure.
- [ ] Evaluate mandatory qualifications.
- [ ] Check compensation when available.
- [ ] Review previous applications.
- [ ] Exclude rejected and closed opportunities.
- [ ] Prevent duplicate recommendations.
- [ ] Identify unverified requirements before recommending.

## 4. Resume and Document Quality

- [ ] Use verified professional experience.
- [ ] Include relevant certifications.
- [ ] Preserve accurate employment dates.
- [ ] Match documents to actual requirements.
- [ ] Avoid inventing skills or achievements.
- [ ] Check spelling and formatting.
- [ ] Verify downloadable files exist.

## 5. Task Completion

- [ ] Confirm the requested action was performed.
- [ ] Verify the resulting output.
- [ ] Confirm saved changes when applicable.
- [ ] Identify unfinished tasks.
- [ ] Do not report success without evidence.

## 6. Error Prevention

- [ ] Check the Error Register.
- [ ] Identify previously documented mistakes.
- [ ] Apply relevant corrective actions.
- [ ] Record significant new errors.
- [ ] Verify that corrections are effective.

## 7. Privacy and Security

- [ ] Do not disclose confidential information.
- [ ] Do not publish credentials or sensitive records.
- [ ] Use approved storage for private information.
- [ ] Confirm information is appropriate for publication.

## 8. Final Quality Gate

Before delivering results, confirm:

**Accuracy:** Verified / Not Verified

**Requirements:** Met / Partially Met / Not Met

**Sources:** Verified / Unverified

**Previous Errors Checked:** Yes / No

**Deliverable Confirmed:** Yes / No

**Outstanding Issues:**

## Important Limitation

This checklist requires deliberate execution.

Its presence in GitHub does not automatically cause
an AI assistant to perform these checks.
